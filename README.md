# Жуйкан · Медицинский центр в Хэйхэ

Готовый сайт с адаптивной вёрсткой, галереей поездок, отзывами, маршрутами и контактами.

## Публикация на GitHub Pages

В **Settings → Pages** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, затем **Save**.

После завершения публикации адрес: https://wwgame28.github.io/Juican-/

Корневой `index.html`, `assets/` и изображения уже готовы. Сборка на GitHub не нужна.

## Исходники

Код находится в `source/`, оригиналы изображений — в `media/`. Сохранены React, Tailwind CSS, shadcn/ui и Motion. Версия для GitHub Pages собирается Vite и не требует сервера или API-ключей.

Node.js 22.13+ и pnpm 11.25.0:

```sh
cd source
pnpm install --frozen-lockfile
pnpm dev
```

После правок:

```sh
pnpm build
pnpm publish:static
```

Затем сохраните изменённые файлы в репозиторий. Старые файлы `assets/` можно удалить, если на них больше не ссылается `index.html`.

## Контент

Услуги, телефон и адрес перенесены с исходного сайта: https://qpwoeiruty17.github.io/med_centre/
Отзывы и фотографии предоставлены владельцем. Источник информации о проезде указан в разделе маршрута. Условия лечения, время работы и поездки необходимо согласовывать с координатором.
