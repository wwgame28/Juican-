# Жуйкан v2: дизайн-план

Сайт медицинского центра «Жуйкан» (瑞康综合门诊) в Хэйхэ. Читатель: житель Благовещенска
и Амурской области, чаще 40+, думает о лечении зубов в Китае. Главная задача страницы:
довести до звонка координатору и снять страх перед дорогой через границу.

## Идея
Центр стоит на другом берегу Амура. Эта река и есть главный образ: первый экран
делится рекой на два берега. На российском берегу заголовок и звонок, на китайском
фото клиники. При загрузке маршрут один раз прочерчивается через реку от Благовещенска
к клинике. В разделе «Дорога» та же схема перерисовывает маршрут, когда человек выбирает
автобус по мосту или теплоход.

Река подписана на двух языках, каждая подпись со своего берега: «Амур» и «黑龙江».

## Палитра
| Имя     | Hex       | Роль |
|---------|-----------|------|
| Бумага  | `#F2F5F3` | фон российского берега, холодный, не кремовый |
| Лёд     | `#DFE8E6` | фон китайского берега и тихих разделов |
| Амур    | `#16313A` | река, заголовки, тёмные панели |
| Текст   | `#1F2E33` | основной текст |
| Фасад   | `#0B7383` | бирюза с фасада клиники: кнопки, маршрут, фокус |
| Печать  | `#B8322A` | только логотип-печать 瑞康 |

## Шрифты
- Literata (оптический размер 72) для заголовков: книжная антиква с каллиграфическим
  контрастом, рифмуется с печатью и китайской письменной культурой.
- Golos Text для текста: разборчивый гротеск, 18px, межстрочный 1.55 (аудитория 40+).
- Noto Serif SC, подмножество из ~25 иероглифов: печать, адрес, «黑龙江».
- Шкала по Брингхерсту: 14 / 18 / 21 / 24 / 36 / 48 / 72.

## Раскладка
```
РУ-берег   [печать] Жуйкан             Лечение Дорога Фото Отзывы   +7 924…
           ● Благовещенск
           Стоматология
           на другом берегу Амура
           текст · [Позвонить координатору] [Канал в Telegram]
           ┆ маршрут
~~~~~~~~~~ Амур ~~~~~~~~~~~~~~~ река ~~~~~~~~~~~~~~~~ 黑龙江 ~~~~~~~~~~~
КН-берег                 ┆
                  ┌──────────────────────────┐ ● Хэйхэ, ул. Ван Су, 112
                  │ фото клиники              │
                  └──────────────────────────┘
```
Дальше: о центре прозой, список лечения без нумерации (это не последовательность),
дорога со схемой и переключателем, шаги поездки с номерами (это последовательность),
лента фото, отзывы цитатами, вопросы, контакты с карточкой «Показать водителю».
Выравнивание по левому краю, колонка текста до 66 знаков.

## Движение
Один оркестрованный момент: маршрут через реку при загрузке. Всё остальное движение
отвечает на действие человека: перерисовка маршрута при смене транспорта, раскрытие
вопросов и отзывов, открытие фото и адреса для водителя (View Transitions там, где
браузер умеет). Без появления каждого раздела при прокрутке. При
`prefers-reduced-motion` всё сразу в конечном состоянии.

## Что пересмотрено после проверки на шаблонность
- Цифры 2012 и 3 000 м² были плитками «большое число + подпись». Стали фразой в тексте.
- Надписи капсом над каждым заголовком убраны, заголовки называют содержание раздела.
- Номера 01–04 у направлений лечения убраны: это не последовательность.
- Двухцветные заголовки («вторая строка серым») убраны.
- Строки через «·» и стрелки в конце ссылок убраны.
